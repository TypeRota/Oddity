# 实现设计

- nte-core/performance: 比较持久化、MangoHud 逐帧 CSV 解析、会话统计、分布与时间线、SVG/PNG 报告. 逐帧采样与硬件计数分开, 原始日志保留在比较目录中.
- nte-service: 在现有启动和游戏生命周期边界配置仅本轮有效的 MangoHud 日志, 采集进程内存与 NVIDIA GPU 指标, 退出后后台完成报告并通知界面. 不更改全局 MangoHud 配置.
- UI: 游戏模式页增加性能比较分类, 复用 SettingGroup / SettingRow / BaseSelect / BaseButton. 沿用应用字体、颜色和间距, 报告使用白底蓝/橙曲线, 保证 PNG 可独立阅读. 环境管理保留在设置.
- 每次会话固定环境信息、游戏版本、显示后端、GameMode/Gamescope 和 VKD3D 参数. 只保存明确允许的字段, 不保存整个进程环境或账号数据.
- 平均 FPS = 总帧数 / 总帧时间; 1% Low = 最慢 1% 帧时间均值的倒数; P95/P99 为逐帧时间分位数; 卡顿时间占比 = >50 ms 的帧时间总和 / 总帧时间. 排除日志前 5 秒初始化, 保留其后全部有效帧, 不自动识别菜单/场景.
- 会话汇总等权计算指标均值. 时间线以日志 elapsed 秒为横轴, 不将两次会话的同一时间视为同一场景. 单侧记录也生成报告; 无数据的指标使用破折号, 未采集的硬件面板省略. 图中仅保留标识、指标、单位和数值, 统计口径放入使用文档.
- 对照 MangoHud 官方日志实现及 mangoplot 方式; 不复制外部代码. FlightlessSomething 的服务器和网页依赖不适合本地启动器, 且未找到明确授权, 不借用实现.
